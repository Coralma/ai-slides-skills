概览

什么是 Claude Code？

Claude Code 是 Anthropic 推出的终端原生 AI 编程工具， 让开发者直接在命令行与完整代码库进行深度对话，自动完成代码编写、调试、重构与测试。

  • 完整代码库感知，无需手动粘贴代码
  • 多文件同步编辑，保持逻辑一致性
  • 支持 Git 操作、运行测试、执行命令
  • 内置权限管控，操作前明确提示

终端原生

在 zsh / bash 中直接运行，不依赖 IDE 插件

深度上下文理解

读取项目结构、依赖关系与历史提交

安全优先

所有文件写入与命令执行需用户确认

快速开始

安装与配置

# 1. 安装 Node.js 18+ (如已安装可跳过)
$ brew install node

# 2. 全局安装 Claude Code
$ npm install -g @anthropic-ai/claude-code

# 3. 进入项目目录并启动
$ cd ~/my-project
$ claude

# 4. 查看版本
$ claude --version
  1.x.x

系统要求

Node.js 18 或更高版本
macOS / Linux / Windows (WSL)

API 密钥配置

首次运行时会引导登录 Anthropic Console 获取密钥，或设置环境变量 ANTHROPIC_API_KEY

企业网络提示

如在代理环境下，需配置 HTTPS_PROXY 环境变量

实际操作

常用命令示例

# 启动交互式会话
$ claude

# 单次查询（非交互式）
$ claude -p "解释这个函数的作用"

# 指定文件上下文
$ claude --file src/main.py

# 切换模型
$ claude --model claude-opus-4-5

# 查看帮助
$ claude --help

交互式会话常用指令

1

/help — 查看所有斜线命令

列出 Claude Code 内置的所有快捷指令

2

/clear — 清除对话上下文

开始新任务前重置上下文，避免干扰

3

/diff — 查看待提交变更

显示 Claude 对文件所做的所有修改

4

/cost — 查看 Token 使用量

实时查看当前会话的 API 消耗统计

高级特性

Agent 模式：自主完成复杂任务

Claude Code 支持 Agent 模式——自主规划与执行多步骤任务， 无需逐步人工确认，适合复杂的重构、迁移或功能开发场景。

1

理解任务目标

分析需求，分解为可执行的子任务序列

2

探索代码库

读取相关文件、测试、文档，建立全局理解

3

执行变更

编辑文件、运行测试、处理报错，循环迭代

4

汇报结果

总结完成的操作，列出所有文件变更供审查

典型 Agent 任务示例

  • 将整个项目从 Python 2 迁移到 Python 3
  • 为所有 API 端点添加输入验证与错误处理
  • 将数据库层从 SQLite 替换为 PostgreSQL
  • 生成完整的 API 文档与使用示例

安全保障

高风险操作（删除文件、外部 API 调用）仍需明确授权，可通过 --permission-mode 精细控制权限级别

安全与合规

企业级安全保障

权限分级管控

三级权限模式：默认（每次确认）、自动接受编辑、完全自主。可根据团队安全策略灵活配置

数据不训练

API 调用模式下，代码内容不用于模型训练。企业客户可签署数据处理协议（DPA）

完整审计追踪

所有文件修改均可通过 Git diff 审查，操作日志完整保存，满足合规审计要求

网络隔离选项

支持配置私有 API 端点，适用于需要网络隔离的金融、保险等高合规行业部署

团队策略管理

通过 CLAUDE.md 文件定义团队规范，统一代码风格、禁止操作列表与最佳实践

使用注意事项

避免将生产数据库凭证、私钥等敏感信息直接粘贴至对话；建议在独立分支上进行大范围变更
